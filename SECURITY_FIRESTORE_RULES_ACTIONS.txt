SECURITY ACTIONS - FIRESTORE RULES

This repaired package adds firestore.rules and firebase.json.

Your current Firebase Console screenshot showed:
  allow read, write: if true;

That is critical because anyone can read/write/delete production data.

Deploy from PowerShell at the project root:

  npm install -g firebase-tools
  firebase login
  firebase use gamesworld-8b301
  firebase deploy --only firestore:rules

After deploy, test:
  npm run typecheck
  npm run lint
  npx expo start

Important compatibility note:
The new rules are a strong emergency lockdown while trying not to break the current app.
The dailyLeaderboard collection still allows authenticated users to update the daily scores array because the current app writes one shared doc per day.
Future safer design: dailyLeaderboard/{dayId}/scores/{uid}, one score document per user.

Manual Firebase Console check after deploy:
- Firestore -> Rules should no longer show the red public warning.
- Anonymous/non-authenticated writes should fail.
- Signed-in users should only write their own user/ladder/season documents.
